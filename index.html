Обвязка текстов ВПР

Локальная страница: шаблон и задания — файлы .txt или .htm / .html (в т.ч. «Веб-страница» из Word), пакетно — несколько файлов или .zip. В архиве результата сохраняются те же имена и расширения; внутри — готовый фрагмент кода для ВПР.

Шаблон

Шаблон — с плейсхолдерами __INSTRUCTION__ … __HINT__ или полный образец (как Код_образец.txt): разбор в плейсхолдеры автоматически. Без файла — встроенный шаблон; при python -m http.server может подтянуться templates/.

Задания

Полные предложения в обвязке даёт только исходный .htm из Word/KIM (в т.ч. из папки задания). Если загрузить уже собранный фрагмент с span.ans, при отдельных строках А–В инструмент лишь подставит текст в шапку и исправит &nbsp; — обрезанный текст в span сам не восстановит.

В выходной HTML всегда подставляются неразрывные пробелы   по простым русским правилам (однобуквенные слова, предлоги «в», «по», «и» и т.д.), в том числе после ответа ИИ.

DeepSeek (ИИ-парсинг)

Ключ сохраняется в localStorage этого браузера. Запросы идут с вашей страницы на сервер DeepSeek; при ошибке «Failed to fetch» часто мешает CORS — откройте страницу через HTTPS-сайт или используйте локальный прокси к API. В запрос уходит исходный файл шаблона (как образец вёрстки) и задание; длинный текст режется примерно до 200k символов на запрос. Режим «полный HTML»: ответ — готовая разметка; у API DeepSeek лимит вывода до 8192 токенов (иначе 400) — при обрыве уменьшите объём задания или шаблона. Ответ DeepSeek при одном файле (первом в пакете) стримится в предпросмотр. Режим JSON: нужны плейсхолдеры в шаблоне; типографские   в финальном HTML задаются автоматически.
